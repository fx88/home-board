# Home Board

Home Board is a personal dashboard web app. This repository starts from the initial Vite + React + TypeScript scaffold; dashboard features are added as follow-up work.

## Getting started

```bash
npm install            # install dependencies
npm run dev            # start the dev server with hot reload
npm run build          # type-check and build for production
npm test --if-present  # run tests (none yet — see below)
npm run lint           # lint with Oxlint
```

No test framework is wired up yet. CI runs `npm test --if-present`, so a `test` script is picked up automatically once tests are added.
